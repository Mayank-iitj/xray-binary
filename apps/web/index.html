X-Ray Binary — Architecture & Defense Principles

Core Innovation

Traditional AV relies on byte signatures, strings, and hashes which attackers alter for zero cost. X-Ray Binary extracts the program execution topology (call graph labelled exclusively by instruction profile deciles, normalized API buckets, and CFG cyclomatic metrics). No names, strings, or raw bytes are ever used, ensuring rename and encryption invariance.

Dual-Scorer Independence

1. Weisfeiler-Lehman Graph Kernel: Deterministic, data-free topological isomorphism test with BLAKE2b hashing.
2. Call-Graph GNN: 3-layer GIN with sum+max pooling readout producing calibrated probabilities and vector embeddings.

Honest Reporting Stance

Packed binaries exhibit unpacker stubs. Rather than guessing, X-Ray Binary checks Shannon entropy and section flags, attempts static unpacking, and marks packed samples as inconclusive_packed when structure is obscured.
